# 从 jiji262/douyin-downloader 借鉴并已落地的能力

当前 PR 已结合本项目 Web/PWA 架构落地：

- 作者发布作品批量扫描
- 作者点赞作品批量扫描
- 合集链接批量扫描
- SQLite 去重与增量模式
- API 指数退避重试复用
- 发布作品首屏 Playwright 浏览器兜底
- Cookie Web 导入 + 浏览器辅助登录
- 真正的多选/全选批量下载
- 后端流式 ZIP，不长期落服务器媒体文件
- 持久化任务中心与任务重试
- SQLite 作品库与搜索/筛选
- GitHub Actions 后端/前端 CI

仍可作为后续阶段继续借鉴的能力：评论采集、视频转写、搜索/热榜、收藏夹/收藏合集、通知推送、附加资源（封面/音乐/JSON）和直播录制。
